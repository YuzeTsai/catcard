# 喵宇宙 MEOWVERSE 🐾

**繁體中文** · [English](README.en.md)

用自家貓咪照片製作的免費抽卡小遊戲，手機與電腦都能玩。

**[立即試玩 →](https://yuzetsai.github.io/catcard/)**

## 介紹

把家裡貓咪的日常照片做成一套收藏卡：先照顧主子、完成任務賺抽卡券，再拆卡包收集每一個可愛瞬間。收集到的卡還能組成 3 張的隊伍，和電腦進行「喵喵對戰」。

- **94 張卡片**，分成 VOL.01、VOL.02、VOL.03 三個系列，有 N / R / SR / SSR 四種稀有度，另有未知的祕密閃卡。
- **純網頁遊戲**：沒有後端、沒有帳號、沒有 AI API 呼叫，也沒有付費抽卡。
- **進度存在自己的瀏覽器**，可以用存檔碼在不同裝置之間搬家。

## 玩法

**賺抽卡券**
- 完成餵食換水、清理貓砂、陪玩任務，每項每天領 1 張抽卡券。
- 三項任務都完成，額外加碼 1 張券，並累計連續照顧的天數。
- 玩魚乾記憶配對、10 秒內點中 8 次逗貓棒，或贏一場喵喵對戰，各可領 1 張券；三種玩法共用每天 3 次。
- 每日任務依台灣時間更新。

**拆卡與收藏**
- 每張券開一包，一包 3 張卡。
- 圖鑑只顯示抽到的卡，重複卡會累計張數；每 5 張重複卡可換 1 張券（每款保留 1 張）。
- 圖鑑上方有成就徽章；卡片詳情有一句小故事、屬性與技能，抽到的卡可以分享。

**喵喵對戰**
- 在「對戰場」選 3 張卡組隊，和電腦輪流出招；電腦的隊伍稀有度和你的相近。
- **屬性相剋**：⚡皮 剋 💤懶，💤懶 剋 💗萌，💗萌 剋 ⚡皮。相剋時傷害 ×1.5，被剋時 ×0.7，所以低稀有度的卡也有機會贏。
- **數值**：心情值（血量）、萌力（攻擊）、護盾（防禦），由稀有度決定。心情值歸零就是「不想玩了」。
- **技能**：每張卡都有「喵喵拳」，再依稀有度從所屬屬性的技能池得到 N 1 招、R 2 招、SR 與以上 3 招；SSR 與祕密閃卡還有一招專屬技能 ★。
- 技能效果有傷害、回復、防禦、削弱對手、蓄力、吸取、無視相剋等；強力技能使用後要休息幾回合。
- **朋友對戰**：選好隊伍後，按「複製我的隊伍代碼」（長得像 `MEOW-13-50-2-6`）或「複製邀請連結」傳給朋友；朋友貼上代碼或點連結，就能挑戰你的隊伍（由電腦操控）。友誼賽不計獎勵與勝場。

遊戲完全在瀏覽器運行。清除瀏覽器資料會清除該瀏覽器的進度；不同網域、瀏覽器、裝置各自存檔。換裝置前，請在頁尾按「複製存檔碼」，到新裝置按「還原存檔」貼上。

## 本機試玩

需要 Python 3。在專案目錄執行：

```sh
python3 -m http.server 8000 --directory site
```

開啟 http://localhost:8000 。

## 更新與發布

遊戲原始檔在 `site/`，沒有套件安裝或建置步驟。

第一次發布，請在儲存庫 **Settings → Pages → Build and deployment → Source** 選 **GitHub Actions**。之後推送到 `main`，工作流程會檢查程式與卡圖，再自動發布 GitHub Pages。

```sh
node --check site/app.js
node --check site/battle.js
node scripts/validate.mjs
git add site README.md README.en.md scripts .github
git commit -m "Update cat cards"
git push origin main
```

### 新增卡片

把圖片放進 `site/assets/`，在 `site/cards.json` 加入卡片資料。保留原有卡片的 `id`，才能維持玩家收藏對應。日常卡片總數會自動計算。

| 欄位 | 必填 | 說明 |
|---|---|---|
| `id`, `name`, `rarity`, `image` | ✅ | 卡號、卡名、稀有度（N / R / SR / SSR / SEC）、`assets/` 內的圖片 |
| `type` | ✅ | 對戰屬性：`萌`、`懶`、`皮` |
| `ex` | SSR、SEC 必填 | 專屬技能，例如 `{"n":"鼻尖碰碰","hit":18,"pierce":true}`；可用欄位見 `site/battle.js` 開頭說明 |
| `story` | 選填 | 一句小故事，顯示在卡片詳情 |
| `series` | 選填 | 卡面的 VOL 編號，沒填就是 VOL.01 |

`node scripts/validate.mjs` 會檢查以上必填欄位與圖片是否存在，沒通過就不會發布。

## 專案結構

- `site/index.html`：遊戲頁面
- `site/style.css`：樣式與閃卡效果
- `site/app.js`：抽卡、任務、小遊戲、成就與存檔
- `site/battle.js`：喵喵對戰（技能、數值與對戰流程）
- `site/cards.json`：卡池資料
- `site/assets/`：貓咪照片
- `scripts/validate.mjs`：卡池與資源檢查
- `.github/workflows/pages.yml`：自動檢查與發布
